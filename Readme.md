## 📖 About

**MYPROJECT1** is a single-page portfolio site for Ahmad Shayan, a web developer and designer based in Lucknow, India. It's hand-built with plain HTML, CSS, and JavaScript — no frameworks, no build step — and leans into a dark, glassmorphic look with a lot of motion: a typewriter hero, scroll-triggered reveals, animated skill bars, and a filterable project grid.

## ✨ Features

- 🎬 Animated hero with a typewriter effect that cycles through job titles
- ⏳ Custom animated preloader on first page load
- 🖱️ Mouse-following cursor glow, plus ripple animations on button clicks
- 🧊 Glassmorphism UI — frosted, blurred cards throughout
- 👀 Scroll-reveal animations via the Intersection Observer API
- 📊 Animated skill bars and stat counters
- 🗂️ Filterable project gallery (All / Web Apps / E-commerce / Portfolio / Business)
- 📱 Fully responsive, with a slide-in mobile nav menu
- 📩 Working contact form with client-side validation, powered by Web3Forms
- 🎯 Scroll-spy navigation that highlights the active section
- 🌈 Dark theme with purple-to-cyan gradient accents

## 🛠️ Tech Stack

## 🚀 Getting Started

No dependencies or build tools required — it's plain HTML/CSS/JS.

```bash
git clone https://github.com/AhmadShayaan19/MYPROJECT1.git
cd MYPROJECT1
```

Then open `index.html` in your browser:

```bash
open index.html        # macOS
start index.html        # Windows
xdg-open index.html     # Linux
```

For live-reloading while you edit, serve it with a local dev server — e.g. VS Code's [Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer) extension.

## 🎨 Customization

- **Colors & theme** — edit the CSS custom properties inside `:root` at the top of `index.html` (`--accent`, `--cyan`, `--bg`, etc.)
- **Typewriter roles** — update the `roles` array near the end of the `<script>` section
- **Projects** — duplicate a `.project-card` block and update its `data-category`, image, and copy
- **Contact form** — swap in your own [Web3Forms](https://web3forms.com/) access key
